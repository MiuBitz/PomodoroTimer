# Changelog

## 1.0.0 - 2026-10-09

- Rebuilt the Windows app with Tauri 2 and Rust.
- Configurable focus sessions, breaks, and cycles with pause/resume and reset.
- Drift-resistant deadlines, rounded countdown, and stable completion state.
- Active runs preserve their original durations when settings change.
- Single-click tray opening and optional startup hidden to tray.
- Live dark/light and color previews, with Cancel restoring saved appearance.
- Bundled SVG interface icons and Inter font for offline use.
- Portable executable, GitHub build workflow, and project webpage adapted from DailyJournal.
